# Data Structures & Algorithms

> Part of my 30-Day Software Engineering Mastery journey.

This repository documents my journey of learning Data Structures & Algorithms from first principles. Rather than simply solving coding problems, the goal is to understand **why** each data structure and algorithm exists, when to use it, and the trade-offs involved.

  - Arrays
  - Linked Lists
  - Stacks
  - Queues
  - Hash Tables
  - Trees
  - Graphs
  - Heaps

- ⚡ Algorithms
  - Searching
  - Sorting
  - Recursion
  - Dynamic Programming
  - Greedy Algorithms
  - Graph Algorithms

- 📈 Big O Analysis
  - Time Complexity
  - Space Complexity
  - Performance Comparisons

- 💻 Coding Challenges
  - LeetCode
  - HackerRank
  - Custom Problems

## Goal

To build a deep understanding of Data Structures & Algorithms and become a better software engineer by focusing on problem-solving, efficiency, and scalability.

*"First make it work. Then make it right. Then make it fast."*
